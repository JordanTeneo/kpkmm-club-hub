# KPKMM Club Hub

A Next.js starter site for **Kelab Peminat Kereta Mini Malaysia**.

## What is included

- Responsive club landing page
- Upcoming-events feature area
- Notice board layout
- Outings gallery layout
- Contact call-to-action

## Run locally

With Node.js installed, run:

```powershell
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Publish on Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in the Vercel dashboard.
3. Keep the default Next.js settings and click **Deploy**.

Vercel will build the site automatically. For the next iteration, connect Vercel Blob (for photo uploads) and a database/auth provider (for event and notice administration).
